## Как устроен файл задачи

Задачи к главам 1.1–1.4 получают данные из переменных в начале программы:

```python
# Задачник, глава 1.1, задача 1.1.1 «Забор вокруг участка» (★☆☆)
# Условие: https://python-theory-makarov.vercel.app/zadachnik/1-1/index.html#p1
#
# Участок прямоугольный. Известны его длина и ширина в метрах. ...
#
# Пример 1
#   данные:
#     length = 30
#     width = 20
#   вывод:
#     Длина забора: 100 м

# Исходные данные (пример 1)
length = 30
width = 20

# Решение
```

С главы 1.5 данные вводятся с клавиатуры через `input()`:

```python
# Задачник, глава 1.5, задача 1.5.1 «Приветствие» (★☆☆)
# Условие: https://python-theory-makarov.vercel.app/zadachnik/1-5/index.html#p1
#
# Программа спрашивает имя и здоровается.
#
# Пример 1
#   ввод:
#     Анна
#   вывод:
#     Привет, Анна!

# Решение
name = input()
```

## Как проверить решение

1. Запустите файл: `python problems/chapter-1-1/task_01.py` (на macOS — `python3`).
2. Подставьте или введите данные примера 1 и сравните вывод с примером символ в символ.
3. Повторите для остальных примеров. Для глав 1.1–1.4 данные меняются в блоке «Исходные данные».
4. Совпали все примеры — отметьте задачу как `решено` в `README.md` папки главы.
