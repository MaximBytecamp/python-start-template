# Как сдавать работы

Пошаговая инструкция с картинками для всех случаев — на сайте курса:
[работа с репозиторием](https://algorthimization-course-vvodnoe.vercel.app/dup02-vvedenie-v-python/repozitoriy/index.html). Здесь — правила, которые проверяет преподаватель.

## Куда класть работу

| Работа | Папка | Пример пути |
|---|---|---|
| домашнее задание | `homework/NN-<тема>/` | `homework/01-variables/task_01.py` |
| практическая работа на паре | `practice/NN-<тема>/` | `practice/01-variables/main.py` |
| задача из задачника по желанию | `problems/chapter-<глава>/` | `problems/chapter-1-3/task_07.py` |
| тест | `exams/quiz-NN-…/README.md` | код результата в таблице |
| контрольная работа | `exams/exam-NN/` | `exams/exam-01/task_03.py` |

Имя новой папки для ДЗ и практической работы берётся из таблицы в `homework/README.md`
и `practice/README.md`: преподаватель дописывает туда строку, когда выдаёт работу.
Задачи задачника, выданные как ДЗ, решаются в папке ДЗ: одна работа — одна папка.

## Имена папок и файлов

| Правило | Правильно | Неправильно |
|---|---|---|
| латинские буквы, цифры, `-` и `_` | `task_01.py` | `задача1.py` |
| без пробелов | `01-variables` | `01 variables` |
| маленькие буквы | `task_01.py` | `Task_01.py` |
| номер двумя цифрами | `task_07.py` | `task_7.py` |
| файл кода — слова через `_` | `task_01.py` | `task-01.py` |
| папка — слова через `-` | `01-variables` | `01_Variables` |
| имя говорит, что внутри | `task_03.py` | `new.py`, `test1.py`, `final2.py` |

Файл кода с дефисом в имени запустить можно, но импортировать в другую программу нельзя:
Python читает `-` как минус. Поэтому в именах `.py` слова разделяются подчёркиванием.

## Сообщение коммита

Первое слово — папка, затем номер работы и что сделано:

| Работа | Сообщение |
|---|---|
| ДЗ 1, все задачи | `homework 01: задачи 1–3` |
| исправление в ДЗ 1 | `homework 01: исправлен вывод в задаче 2` |
| задачник | `problems 1.3: задачи 1–5` |
| практическая работа | `practice 02: калькулятор скидки` |
| тест | `quiz 01: код результата` |
| контрольная | `exam 01: вариант 2, задачи 1–10` |

Сообщения `update`, `fix`, `файлы`, `123` не принимаются: по ним нельзя понять, что изменилось.

## Перед отправкой

1. Каждый файл запущен, вывод совпадает с примерами задания.
2. Файлы лежат в нужной папке, имена по правилам выше.
3. В `README.md` папки ДЗ заполнены таблицы «Файлы» и «Проверка».
4. Если для решения использовался ИИ, в начале файла есть комментарий: что спросили и что взято из ответа.
5. Работа ушла на GitHub: на странице репозитория виден ваш коммит.

Все работы загружаются в ветку `main`. Отдельные ветки и Pull Request для заданий не создаются.
