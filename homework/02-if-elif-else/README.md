# ДЗ 2. Главы 2.3–2.5: диапазоны, if / elif / else, вложенные условия

Четырнадцать задач. В задачах 1–4 диапазон проверяется в условии `if`, в задачах 5–10 нужна
цепочка `if` / `elif` / `else`, в задачах 11–14 — вложенные условия. Для решения достаточно
глав 1.1–2.5: сравнений, `and`, `or`, `not`, двойного сравнения, ветвления и вложенных условий.

[2.5 Вложенные условия](https://python-theory-makarov.vercel.app/temy/14-vlozhennye-usloviya/index.html)
