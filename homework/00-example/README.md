# ДЗ 0. Образец оформления

Эта папка — пример. Задачи взяты из разборов справочника, их решения есть в главах 1.1 и 1.5.

## Задание

1. Посчитать стоимость поездки на 500 км: топливо плюс проживание
   ([глава 1.1, §4](https://python-theory-makarov.vercel.app/temy/01-peremennye/index.html)).
2. Ввести два целых числа и вывести их среднее
   ([глава 1.5, §5](https://python-theory-makarov.vercel.app/temy/05-input/index.html)).

## Файлы

| Файл | Задача |
|---|---|
| [`task_01.py`](task_01.py) | стоимость поездки |
| [`task_02.py`](task_02.py) | среднее двух чисел |

## Проверка

| Файл | Ввод | Вывод |
|---|---|---|
| `task_01.py` | — | `Общая стоимость: 4395.83 руб.` в последней строке |
| `task_02.py` | `5`, `8` | `Среднее значение: 6.5` |
| `task_02.py` | `7`, `4` | `Среднее значение: 5.5` |
