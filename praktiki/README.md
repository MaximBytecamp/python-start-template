# Практические работы

Работы, которые выполняются на занятии. Одна работа — одна папка `pr-NN-<тема>`.
Файлы, созданные на паре, кладутся в папку этой работы.

| Папка | Работа | Глава |
|---|---|---|
| [`pr-00-pervyy-proekt`](pr-00-pervyy-proekt/README.md) | первый проект в VS Code | 0 |

Новую работу заводите так: создайте папку со следующим номером, например `pr-01-peremennye`,
положите в неё файлы `.py` и `README.md` с описанием работы.
