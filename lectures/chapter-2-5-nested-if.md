## Что изучили

1. Вложенное условие — `if` внутри блока другого `if`. Внутренняя проверка запускается, только когда программа вошла во внешнюю ветку.
2. Каждый уровень вложения добавляет четыре пробела отступа: действие внутри второго `if` стоит на восьми пробелах.
3. `else` относится к тому `if`, с которым стоит на одном уровне отступа.
4. Вложенный `if` может стоять и в ветке `else`: тогда до него программа доходит после ложного внешнего условия. Внутри ветки можно использовать и цепочку `if` / `elif` / `else`.
5. Внешний блок может выполнять свои действия до внутреннего `if`.
6. Если действие одно и обе проверки равноправны, вложение заменяют условием с `and`: `if age >= 18 and has_ticket:`. Вложение оставляют, когда после первой проверки есть отдельные действия или разные ответы.
7. Код читают по уровням: сначала внешнюю проверку, затем тот путь, по которому программа вошла внутрь. Если уровней больше двух-трёх, задачу делят на более простые проверки.

## Термины

| Термин | Значение |
|---|---|
| вложенное условие | `if` внутри блока другого `if` |
| уровень вложения | глубина блока; каждый уровень — ещё четыре пробела отступа |
| внешний и внутренний `else` | `else`, выровненный с внешним или с внутренним `if` |

## Пример из главы: возраст и билет

```python
age = 20
has_ticket = False
if age >= 18:
    if has_ticket:
        print("Вход разрешён")
    else:
        print("Нет билета")
else:
    print("Вход закрыт по возрасту")
# вывод: Нет билета
```

## Частые ошибки

| Что написано | Что произойдёт | Как правильно |
|---|---|---|
| внутренний `if` без дополнительного отступа | он станет отдельной проверкой, не зависящей от внешней | добавить четыре пробела |
| `else` выровнен не с тем `if` | сообщение появится для другого случая | проверить уровни отступов |
| нет действия внутри второго `if` | `IndentationError` | добавить блок или временно написать `pass` |
| четыре-пять уровней вложения | путь выполнения трудно проследить | разделить условие на несколько более простых проверок |
| два вложенных `if` для одного действия | код длиннее необходимого | условие с `and` |
