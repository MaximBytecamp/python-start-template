## Что изучили

1. Именованные параметры передаются по имени через `=` и стоят после всех выводимых значений.
2. `sep` задаёт разделитель между значениями, по умолчанию пробел `" "`. Разделитель ставится только между значениями: `print(2026, 9, 4, sep=".")` выводит `2026.9.4`. `sep=""` убирает разделитель.
3. `end` задаёт, что добавляется в конце вывода, по умолчанию перевод строки `"\n"`. С `end=""` следующий `print()` продолжает ту же строку. Последний вызов оставляют без `end`, чтобы завершить строку.
4. Управляющие последовательности: `\n` — перевод строки, `\t` — табуляция, `\\` — обратный слеш, `\"` — кавычка внутри строки.
5. `sep` и `end` можно передать в одном вызове в любом порядке между собой.
6. Выбор: если разделитель одинаков для многих значений, берётся `sep`; если между значениями разный текст — f-строка.

## Термины

| Термин | Значение |
|---|---|
| именованный параметр | параметр, который передаётся по имени: `sep=", "` |
| значение по умолчанию | значение параметра, которое подставляется, если параметр не указан |
| `sep` | разделитель между значениями в одном вызове `print()` |
| `end` | строка, которая добавляется после вывода |
| управляющая последовательность | запись с обратным слешем для символа без видимого начертания: `\n`, `\t` |

## Примеры из главы

```python
print(1, 2, 3, sep=" - ")              # 1 - 2 - 3
print("Иванов", "Python", 5, sep=" | ") # Иванов | Python | 5
print(1, 2, 3, sep="\n")                # каждое число с новой строки

print("Загрузка: ", end="")
print("#", end="")
print("#", end="")
print(" готово")                        # Загрузка: ## готово
```

## Частые ошибки

| Что написано | Что произойдёт | Как правильно |
|---|---|---|
| `print(1, 2, sep=", ", 3)` | `SyntaxError`: значение после именованного параметра | `print(1, 2, 3, sep=", ")` |
| `print("a", "b", sep)` | `NameError`: `sep` без `=` читается как имя переменной | `print("a", "b", sep="-")` |
| `print("Загрузка", end="")` последней строкой | приглашение терминала оказывается в той же строке | завершить вывод обычным `print()` |
| `print("C:\name")` | `\n` внутри пути выводится как перевод строки | удвоить слеш: `"C:\\name"` |
