## Что изучили

1. Словесные условия задач переводятся в выражения: «каждое» — цепочка `and`, «хотя бы одно» — цепочка `or`, «только одно» — перечисление подходящих случаев, соединённых `or`.
2. Составное условие собирается из простых проверок: `A % 2 == 0` — чётное, `A % 2 != 0` — нечётное, `A % 3 == 0` — кратно трём, `A < 0` — отрицательное.
3. `and` прекращает вычисление на первом `False`, `or` — на первом `True`: результат уже известен.
4. «Ровно одно из двух чётное»: `(A % 2 == 0 and B % 2 != 0) or (A % 2 != 0 and B % 2 == 0)`. От «хотя бы одного» оно отличается случаем, когда чётны оба числа.
5. «Ни одного» и «не все» получаются через `not`. По законам де Моргана при раскрытии скобок после `not` каждая проверка меняется на противоположную, а `and` и `or` меняются местами: `not (A < 0 or B < 0)` равно `A >= 0 and B >= 0`.
6. Длинное условие собирают по шагам: выписать требования, записать каждое простой проверкой, выбрать связку, дать промежуточным проверкам имена.
7. Сравнение записывается у каждого числа: `A < 0 or B < 0`. Запись `A or B < 0` проверяет другое условие.

## Термины

| Термин | Значение |
|---|---|
| составное условие | выражение из нескольких простых проверок, соединённых `and`, `or`, `not` |
| «каждое», «хотя бы одно», «только одно» | формулировки условий: `and`, `or`, сочетание `and` и `or` |
| законы де Моргана | `not (a or b)` равно `not a and not b`; `not (a and b)` равно `not a or not b` |
| кратность | делимость без остатка, проверяется как `A % n == 0` |

## Примеры из главы: ровно одно чётное и условие с именами

```python
A, B = 4, 7
print((A % 2 == 0 and B % 2 != 0) or (A % 2 != 0 and B % 2 == 0))   # True

is_adult = age >= 18
is_experienced = experience >= 3
has_no_debt = debt == 0
print(is_adult and is_experienced and has_no_debt)
```

## Частые ошибки

| Что написано | Что произойдёт | Как правильно |
|---|---|---|
| `A % 2 == 0 or B % 2 == 0` для «ровно одного» | условие истинно и когда оба числа чётные | развернуть в два случая через `and` и соединить их `or` |
| `A or B or C < 0` | сравнение относится только к `C`, результат почти всегда `True` | `A < 0 or B < 0 or C < 0` |
| `not A < 0 or B < 0` | `not` применился только к первой проверке | `not (A < 0 or B < 0)` |
| `A % 2 = 0` | `SyntaxError`: присваивание вместо сравнения | `A % 2 == 0` |
| `A % 2 == 0 and != 0` | `SyntaxError`: у второго сравнения нет операнда | повторить проверяемое значение полностью |
