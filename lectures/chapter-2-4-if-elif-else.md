## Что изучили

1. Ветвление выбирает действия по результату условия: при `True` блок выполняется, при `False` пропускается или выбирается другая ветка. Условие — любое выражение с логическим результатом.
2. После условия ставится двоеточие. Строки блока имеют одинаковый отступ — обычно четыре пробела. Отступ — часть синтаксиса: строка без отступа после блока выполняется при любом результате проверки.
3. `else` («иначе») выполняется, когда условие `if` ложно. Собственного условия у `else` нет.
4. `elif` («иначе, если») добавляет проверку между `if` и необязательным `else`.
5. Цепочка `if` / `elif` / `else` проверяется сверху вниз и останавливается на первой истинной ветке: выполняется не более одной ветки. Поэтому более строгие условия ставят раньше общих.
6. Несколько отдельных `if` проверяются независимо, и могут выполниться сразу несколько блоков.

## Термины

| Термин | Значение |
|---|---|
| ветвление | конструкция, которая выбирает действия по результату условия |
| блок | строки с одинаковым отступом после двоеточия |
| `if`, `elif`, `else` | «если», «иначе, если», «иначе» |
| `IndentationError` | ошибка: нет нужного отступа или он лишний |

## Пример из главы: тариф доставки

```python
order_total = 3200
if order_total >= 5000:
    delivery = 0
elif order_total >= 2000:
    delivery = 250
else:
    delivery = 500
final_total = order_total + delivery
print(f"Доставка: {delivery} руб.")    # Доставка: 250 руб.
print(f"К оплате: {final_total} руб.")  # К оплате: 3450 руб.
```

## Частые ошибки

| Что написано | Что произойдёт | Как правильно |
|---|---|---|
| `if age >= 18` | `SyntaxError`: нет двоеточия | `if age >= 18:` |
| `if age = 18:` | `SyntaxError`: присваивание вместо сравнения | `if age == 18:` |
| строка после `if` без отступа | `IndentationError` | отступ в четыре пробела |
| `else age < 18:` | `SyntaxError`: у `else` нет условия | `elif age < 18:` или просто `else:` |
| сначала `score >= 70`, потом `>= 90` | высокие оценки попадут в первую ветку | расположить границы от большей к меньшей |
