## Что изучили

1. Оператор — знак или слово, которое задаёт действие. Значения, над которыми выполняется действие, называются операндами. Один оператор работает по-разному с разными типами: `2 + 3` складывает, `"Py" + "thon"` склеивает.
2. Арифметические операторы: `+ - * / // % **`.
3. Операторы сравнения `== != > < >= <=` возвращают `True` или `False` и значения не меняют. `=` присваивает, `==` сравнивает.
4. Составные присваивания существуют для всех арифметических операций: `+=`, `-=`, `*=`, `/=`, `//=`, `%=`, `**=`.
5. Унарный минус меняет знак: `-temperature`.
6. Порядок вычисления: скобки → `**` → `* / // %` → `+ -`. Операторы одного уровня выполняются слева направо. Степень — исключение, она выполняется справа налево: `2 ** 3 ** 2` — это `2 ** 9`, то есть `512`.

## Термины

| Термин | Значение |
|---|---|
| оператор | знак или слово, задающее действие: `+`, `==`, `+=` |
| операнд | значение, над которым выполняется действие |
| приоритет | порядок, в котором выполняются операторы в выражении |
| унарный оператор | оператор с одним операндом: `-x` |
| `ZeroDivisionError` | ошибка деления на ноль |

## Порядок вычисления

```python
print(2 + 3 * 4)    # 14
print((2 + 3) * 4)  # 20
print(2 ** 3 ** 2)  # 512: 2 ** (3 ** 2)

score = 10
score += 5
score *= 2
score -= 3
print(score)        # 27
```

## Частые ошибки

| Что написано | Что произойдёт | Как правильно |
|---|---|---|
| `x = 5`, когда нужно проверить, равно ли `x` пяти | `x` получает значение `5`, сравнения нет | `x == 5` даёт `True` или `False` |
| `2 ^ 3` для степени | получается `1`: `^` — другая операция | `2 ** 3` |
| `10 / 0` | `ZeroDivisionError` | проверить делитель |
| `2 + 3 * 4`, ожидая `20` | получается `14` | `(2 + 3) * 4` |
