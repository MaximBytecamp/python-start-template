## Что изучили

1. Логический тип `bool` — тип с двумя значениями: `True` (истина) и `False` (ложь). Оба слова пишутся с заглавной буквы и без кавычек. `true` вызывает `NameError`, `"True"` в кавычках — строка.
2. Логическое значение чаще всего получают как результат сравнения: `age > 18` даёт `True` или `False`. Операторов сравнения шесть: `==`, `!=`, `>`, `<`, `>=`, `<=`. Один знак `=` — присваивание, два `==` — сравнение.
3. `bool` — подкласс `int`: `True` равно 1, `False` равно 0, поэтому `True + True` даёт `2`. Сумма логических значений равна количеству истинных проверок.
4. `bool()` приводит значение к логическому типу: `0` и пустая строка дают `False`, остальные числа и строки — `True`. `bool("нет")` — это `True`, поэтому ответ пользователя проверяют сравнением: `answer == "да"`.
5. `and` даёт `True`, только когда истинны оба условия. `or` даёт `True`, если истинно хотя бы одно, в том числе оба. `not` меняет значение на противоположное.
6. Приоритет: сначала `not`, затем `and`, затем `or`. В выражениях с несколькими операциями ставят скобки.
7. Результат проверки сохраняют в переменную с именем на `is_` или `has_`: `is_adult and is_experienced` читается как фраза.

## Термины

| Термин | Значение |
|---|---|
| `bool` | логический тип со значениями `True` и `False` |
| операция сравнения | выражение вида `a > b`, результат — `True` или `False` |
| `and`, `or`, `not` | логические операции: «оба», «хотя бы одно», «наоборот» |
| таблица истинности | таблица всех сочетаний значений и результата операции для каждого |
| приоритет | порядок вычисления операций: `not` → `and` → `or` |

## Пример из главы: анкета

```python
age = int(input("Ваш возраст: "))
experience = int(input("Стаж работы, лет: "))
is_adult = age >= 18
is_experienced = experience >= 3
print("Совершеннолетний:", is_adult)
print("Подходит на позицию:", is_adult and is_experienced)
print("Нужно обучение:", not is_experienced)
# ввели 20 и 1: True, False, True
```

## Частые ошибки

| Что написано | Что произойдёт | Как правильно |
|---|---|---|
| `x = true` | `NameError`: регистр имеет значение | `x = True` |
| `x = "True"` | в переменной строка, а не логическое значение | `x = True`, без кавычек |
| `age > 18 and < 65` | `SyntaxError`: у второго сравнения нет левой части | `age > 18 and age < 65` |
| `x = 5 and y = 3` | `SyntaxError`: присваивание внутри выражения | сначала присвоить, потом проверять |
| `0.1 + 0.2 == 0.3` | `False`: дробные числа хранятся неточно | `round(a + b, 2) == 0.3` |
