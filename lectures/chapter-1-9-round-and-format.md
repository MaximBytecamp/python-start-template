## Что изучили

1. Две задачи: получить округлённое число для дальнейших расчётов — `round(value, 2)`; показать на экране два знака — `f"{value:.2f}"`.
2. `round()` возвращает новое значение, исходная переменная не меняется: `x = round(x, 2)`.
3. `round(value)` без второго аргумента возвращает `int`; `round(3.6, 0)` возвращает `float` `4.0`.
4. Половины округляются к ближайшему чётному: `round(2.5)` равно `2`, `round(3.5)` равно `4`.
5. Формат `.2f` дописывает нули: `f"{12.5:.2f}"` даёт `12.50`.
6. `round()` даёт число, f-строка — текст. Промежуточные значения не округляют; округляют итог или только вывод.

## Термины

| Термин | Значение |
|---|---|
| `round(value, n)` | округление числа до `n` знаков после точки |
| формат `.2f` | вывод числа в f-строке с двумя знаками после точки |
| округление к чётному | правило для половин: `2.5` → `2`, `3.5` → `4` |

## Пример из главы: средний чек

```python
total = 1250
orders = 6
average = total / orders
with_discount = average * 0.9
print(f"Средний чек: {average:.2f} руб.")         # 208.33
print(f"После скидки: {with_discount:.2f} руб.")  # 187.50
```

## Частые ошибки

| Что написано | Что произойдёт | Как правильно |
|---|---|---|
| `round(x, 2)` без сохранения | `x` не меняется | `x = round(x, 2)` |
| `f"{price.2f}"` | `SyntaxError`: пропущено двоеточие | `f"{price:.2f}"` |
| `round(2.5)`, ожидая `3` | получается `2` | учитывать правило для половин |
| округление после каждого действия | ошибка накапливается | округлять итог или только вывод |
