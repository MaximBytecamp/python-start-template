## Что изучили

1. Тип данных определяет, какие значения хранит переменная и какие операции над ними допустимы. В Python тип определяется по значению в момент присваивания (динамическая типизация). Узнать тип — `type(x)`.
2. `int` — целые числа без ограничения величины. Операции: `+ - * / // % **`. Деление `/` всегда даёт `float`: `10 / 2` равно `5.0`.
3. `float` — числа с дробной частью, разделитель — точка. Если в выражении есть `int` и `float`, результат дробный. `0.1 + 0.2` даёт `0.30000000000000004`, поэтому дробные числа при выводе округляют, а через `==` не сравнивают.
4. `str` — строка в двойных, одинарных или тройных кавычках. `+` склеивает строки, `*` повторяет, `len()` считает символы.
5. `bool` хранит `True` или `False` и получается при сравнении. `None` означает «значения пока нет».
6. `"10"` и `10` — разные значения: `"10" * 2` даёт `1010`, `10 * 2` даёт `20`.
7. Преобразование: `int()`, `float()`, `str()`. `int("3.5")` — ошибка `ValueError`; `int(3.99)` даёт `3`: дробная часть отбрасывается.

## Термины

| Термин | Значение |
|---|---|
| тип данных | вид значения: от него зависят допустимые операции |
| `int`, `float`, `str`, `bool` | целое число, дробное число, строка, логическое значение |
| `None` | значение со смыслом «данных ещё нет» |
| `TypeError` | ошибка: операция не определена для такой пары типов, например `"10" + 10` |
| `ValueError` | ошибка: значение нельзя преобразовать, например `int("3.5")` |

## Строка с цифрами и число

```python
x = "10"
y = 10
print(type(x))      # <class 'str'>
print(type(y))      # <class 'int'>
print(x * 2)        # 1010
print(y * 2)        # 20
print(int(x) + 10)  # 20
```

## Частые ошибки

| Что написано | Что произойдёт | Как правильно |
|---|---|---|
| `"10" + 10` | `TypeError: can only concatenate str (not "int") to str` | `int("10") + 10` или `"10" + str(10)` |
| `int("3.5")` | `ValueError: invalid literal for int() with base 10: '3.5'` | `float("3.5")` или `int(float("3.5"))` |
| `x = 3,14` | в `x` записывается пара значений: `print(x)` выводит `(3, 14)` | `x = 3.14` |
| `print(10 / 2)`, ожидая `5` | выведет `5.0` | `10 // 2`, если нужен целый результат |
| `print("Итого: " + total)` при числе `total` | `TypeError` | `print(f"Итого: {total}")` |
