## Что изучили

1. Запись `a <= x <= b` проверяет две границы сразу: `x` не меньше `a` и не больше `b`. Она равносильна `a <= x and x <= b`, но среднее выражение вычисляется один раз.
2. Цепочка, как и `and`, прекращает проверку на первом ложном сравнении.
3. Знаки `<=` и `>=` включают границу в диапазон, `<` и `>` исключают. Знаки в одной цепочке можно сочетать: в `1 <= x < 3` число 1 входит в диапазон, число 3 — нет.
4. Границы записывают по возрастанию: меньшая граница, переменная, большая граница. Запись `1 <= x >= 3` означает «x не меньше обеих границ».
5. Для двух величин, например координат точки, составляют две цепочки и соединяют их `and`: `1 <= x <= 3 and -3 <= y <= 1`.
6. Цепочка описывает один непрерывный диапазон. Два раздельных диапазона записывают через `or`: `temperature < -10 or temperature > 35`.

## Термины

| Термин | Значение |
|---|---|
| цепочка сравнений | запись вида `a <= x <= b`: несколько сравнений без повторения переменной |
| включённая граница | крайнее значение, которое входит в диапазон: знаки `<=`, `>=` |
| строгая граница | крайнее значение, которое не входит в диапазон: знаки `<`, `>` |

## Пример из главы: точка в прямоугольнике

```python
x = 2
y = 0
inside_x = 1 <= x <= 3
inside_y = -3 <= y <= 1
inside_area = inside_x and inside_y
print(inside_area)   # True
```

## Частые ошибки

| Что написано | Что произойдёт | Как правильно |
|---|---|---|
| `1 <= x >= 3` | проверяется, что `x` не меньше обеих границ | `1 <= x <= 3` |
| `x >= 1 or x <= 3` | условие истинно почти для любого числа | `x >= 1 and x <= 3` или цепочка |
| `1 < x < 3`, когда края подходят | значения 1 и 3 будут исключены | `1 <= x <= 3` |
| `1 <= x <= 3 and -3 <= 1` | во второй проверке потеряна переменная `y` | `1 <= x <= 3 and -3 <= y <= 1` |
