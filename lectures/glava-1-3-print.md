## Что изучили

1. `print()` выводит данные в терминал. Результата в программу она не возвращает: после `x = print("текст")` в `x` лежит `None`.
2. Текст в кавычках выводится как есть, имя без кавычек — значением переменной. `print(name)` и `print("name")` выводят разное.
3. В скобках может стоять выражение: сначала оно вычисляется, потом печатается результат.
4. Несколько значений через запятую выводятся в одну строку через пробел. Значения могут быть разных типов. `print()` без аргументов выводит пустую строку.
5. f-строка — строка с буквой `f` перед кавычкой; значения и выражения подставляются в фигурных скобках: `f"Имя: {name}"`. Запись `{price:.2f}` выводит число с двумя знаками после точки.
6. Без буквы `f` фигурные скобки выводятся буквально, ошибки при этом нет.
7. Выбор способа: запятая — быстрый вывод пары значений; f-строка — основной способ; `+` требует `str()` и легко даёт `TypeError`.
8. `print()` помогает при отладке: `print("x =", x, type(x))` показывает значение и тип на нужном шаге. После проверки такие строки удаляют.

## Термины

| Термин | Значение |
|---|---|
| аргумент | значение, которое передаётся функции в скобках |
| f-строка | строка вида `f"…{значение}…"`, в которую подставляются значения |
| форматирование `:.2f` | вывод числа с двумя знаками после точки внутри f-строки |
| отладочный вывод | временный `print()`, который показывает значение переменной на шаге программы |

## Три способа вывести текст со значением

```python
name = "Alice"
age = 25
total = 4395.83

print("Имя:", name, "Возраст:", age)    # запятая, пробел ставится между значениями
print(f"Имя: {name}, возраст: {age}")   # f-строка
print("Итого: " + str(total) + " руб.") # плюс, нужен str()
```

## Частые ошибки

| Что написано | Что произойдёт | Как правильно |
|---|---|---|
| `print("Итого: " + total)` | `TypeError`, если `total` — число | `print(f"Итого: {total}")` |
| `print("Возраст: {age}")` | выведутся фигурные скобки: забыта буква `f` | `print(f"Возраст: {age}")` |
| `print("Привет)` | `SyntaxError`: кавычка не закрыта | кавычки и скобки закрываются парами |
| `Print("Привет")` | `NameError`: регистр различается | встроенные функции пишутся строчными буквами |
| `x = print(2 + 2)` | на экране `4`, в `x` — `None` | `x = 2 + 2`, затем `print(x)` |
