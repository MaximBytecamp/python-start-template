## Что изучили

1. `/` — точное деление, результат всегда `float`: `6 / 3` равно `2.0`.
2. `//` — целочисленное деление: сколько раз делитель целиком помещается в делимом. `45 // 4` равно `11`. Если один из операндов `float`, результат тоже `float`: `5 // 2.0` равно `2.0`.
3. `%` — остаток: `45 % 4` равно `1`. Проверка: `45 = 4 * 11 + 1`.
4. Пару `//` и `%` применяют, когда нужно перевести секунды в минуты и секунды, посчитать сдачу, число страниц или коробок.
5. Цифры числа: `n % 10` — последняя цифра, `n % 100` — две последние; `n // 10` убирает последнюю цифру; `n // 10 % 10` — цифра десятков.
6. Чётность: `n % 2 == 0`.
7. Для отрицательных чисел `//` округляет вниз: `-7 // 2` равно `-4`.
8. Деление на ноль любым из трёх операторов даёт `ZeroDivisionError`.

## Термины

| Термин | Значение |
|---|---|
| целочисленное деление `//` | целая часть результата деления |
| остаток `%` | то, что остаётся после целочисленного деления: `45 % 4` равно `1` |

## Разбор из главы: число по цифрам

```python
number = int(input("Введите трёхзначное число: "))
units = number % 10         # единицы
tens = number // 10 % 10    # десятки
hundreds = number // 100    # сотни
print(f"Сотни: {hundreds}, десятки: {tens}, единицы: {units}")
print(f"Сумма цифр: {hundreds + tens + units}")   # для 254: 11
```

## Частые ошибки

| Что написано | Что произойдёт | Как правильно |
|---|---|---|
| `print(6 / 3)`, ожидая `2` | выведет `2.0` | `6 // 3` |
| `number / 10` для последней цифры | получается дробь | `number % 10` |
| `5 // 2.0`, ожидая `int` | выведет `2.0` | `int(5 // 2.0)` |
| `-7 // 2`, ожидая `-3` | получается `-4` | проверять результат на отрицательных числах |
