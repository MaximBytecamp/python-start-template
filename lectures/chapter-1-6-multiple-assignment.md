## Что изучили

1. `a, b, c = 1, 2, 3` присваивает значения по порядку: первое значение — первому имени, второе — второму, третье — третьему.
2. Строка выполняется в два шага: сначала полностью вычисляется правая часть, затем значения присваиваются именам слева. В правой части используются старые значения переменных.
3. Имён слева и значений справа должно быть поровну, иначе `ValueError: too many values to unpack` или `not enough values to unpack`.
4. Обмен значениями одной строкой: `a, b = b, a`. Две строки `a = b` и `b = a` обмен не выполняют: оба имени получают одно значение.
5. `x = y = z = 0` присваивает одно значение нескольким именам.
6. В одну строку объединяют связанные по смыслу значения: пару координат, день, месяц и год.

## Термины

| Термин | Значение |
|---|---|
| множественное присваивание | присваивание нескольким именам в одной строке: `a, b = 1, 2` |
| цепочка присваиваний | одно значение нескольким именам: `x = y = 0` |
| обмен значениями | `a, b = b, a` — переменные меняются значениями без третьей переменной |

## Разворот трёх значений

```python
a = 1
b = 2
c = 3
a, b, c = c, b, a
print(a, b, c)   # 3 2 1
```

## Частые ошибки

| Что написано | Что произойдёт | Как правильно |
|---|---|---|
| `a, b = 1, 2, 3` | `ValueError: too many values to unpack (expected 2)` | слева и справа поровну |
| `a, b, c = 1, 2` | `ValueError: not enough values to unpack` | слева и справа поровну |
| `a = b`, затем `b = a` | оба имени получают одно значение | `a, b = b, a` |
| `a = 1, 2` | в `a` оказывается пара значений | `a, b = 1, 2`, если нужны две переменные |
