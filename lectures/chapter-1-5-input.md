## Что изучили

1. `input()` получает данные с клавиатуры. На этой строке программа останавливается и продолжает работу, когда пользователь наберёт текст и нажмёт Enter. Остановить программу на этом месте — Ctrl + C.
2. Текст в скобках — подсказка. В её конце ставится пробел, в подсказке указывается величина и единица измерения: `"Расстояние, км: "`.
3. `input()` всегда возвращает строку `str`, даже если введены цифры.
4. Число получают преобразованием прямо в строке ввода. `int(input(...))` — для количества в штуках: людей, билетов, этажей. `float(input(...))` — для измеряемых величин: веса, расстояния, цены.
5. Каждый `input()` — отдельная остановка программы.
6. Дробное в целое: `int(6.9)` даёт `6` (отбросить дробную часть), `round(6.9)` даёт `7` (округлить), `//` даёт целую часть деления.
7. При вводе `18 лет`, `18.5` или пустой строки `int()` останавливает программу с `ValueError`. Запятую в дробном числе заменяют на точку: `float(raw.replace(",", "."))`.

## Термины

| Термин | Значение |
|---|---|
| подсказка | текст в скобках `input()`, который видит пользователь перед вводом |
| преобразование при вводе | запись `int(input(...))` или `float(input(...))` |
| `ValueError` | ошибка: введённую строку нельзя прочитать как число |

## Разбор из главы: среднее двух чисел

```python
num1 = int(input("Введите первое число: "))
num2 = int(input("Введите второе число: "))
average = (num1 + num2) / 2
print("Среднее значение:", average)   # для 5 и 8: 6.5
```

## Частые ошибки

| Что написано | Что произойдёт | Как правильно |
|---|---|---|
| `age = input("Возраст: ")`, затем `age + 1` | `TypeError`: к строке нельзя прибавить число | `age = int(input("Возраст: "))` |
| `n = input()`, затем `n * 2` | при вводе `18` выводится `1818` вместо `36` | `n = int(input())` |
| `int(input("Вес: "))` для `72.5` | `ValueError` | `float(input("Вес, кг: "))` |
| `int(input("Возраст: ")` | `SyntaxError`: не закрыта вторая скобка | закрыть обе скобки: `int(input("Возраст: "))` |
| `name = print("Имя: ")` | в `name` оказывается `None` | для ввода нужен `input()` |
