## Что изучили

1. Переменная — имя для данных, с которыми работает программа. Значение можно записать, использовать в вычислении и заменить новым.
2. Запись `имя = значение` — операция присваивания: сначала вычисляется правая часть, затем результат записывается в переменную слева. Поэтому строка `x = x + 1` допустима: справа берётся старое значение `x`, в `x` записывается новое.
3. Правила языка для имени. Имя состоит из букв, цифр и подчёркиваний и не начинается с цифры. Регистр различается: `distance` и `Distance` — разные имена. Ключевые слова (`for`, `if`, `import`) именами быть не могут.
4. Правила читаемости: нижний регистр и подчёркивания (`fuel_price`), имя называет смысл данных, имена встроенных функций (`print`, `input`) не занимаются, имена пишутся латиницей.
5. Порядок программы: исходные данные наверху, расчёт отдельными строками, вывод в конце. Промежуточный результат получает своё имя и дальше используется по имени.
6. Составное присваивание `x += 5` записывает то же, что `x = x + 5`; так же работают `-=`, `*=`, `/=`. Строки выполняются сверху вниз, поэтому порядок присваиваний меняет результат.
7. `print()` показывает готовый результат. Вычисления выносятся в отдельные строки.

## Термины

| Термин | Значение |
|---|---|
| переменная | имя, по которому программа хранит значение и обращается к нему |
| присваивание | запись значения в переменную знаком `=`; правая часть вычисляется первой |
| составное присваивание | `+=`, `-=`, `*=`, `/=`: взять текущее значение, изменить и записать обратно |
| `NameError` | ошибка: имя используется до присваивания или написано с опечаткой |

## Разбор из главы: стоимость поездки

```python
# Исходные данные
distance = 500
fuel_price = 45.5
fuel_efficiency = 12
cost_home = 2500

# Расчёт
fuel_cost = (distance / fuel_efficiency) * fuel_price
total_cost = fuel_cost + cost_home

# Вывод
print(f"Расходы на топливо: {fuel_cost:.2f} руб.")
print(f"Общая стоимость: {total_cost:.2f} руб.")
```

## Частые ошибки

| Что написано | Что произойдёт | Как правильно |
|---|---|---|
| `print(summ)` до присваивания | `NameError: name 'summ' is not defined` | сначала присвоить значение, потом использовать |
| `5 = x` | `SyntaxError`: слева от `=` стоит значение | `x = 5` |
| `total = fuell + home` с опечаткой | `NameError` | скопировать имя из строки, где оно задано |
| `x = x + 1` в первой строке | `NameError`: справа стоит имя `x`, которому ещё не присвоено значение | задать начальное значение: `x = 0` |
| `print = "текст"` | имя `print` теперь обозначает строку; следующий вызов `print(...)` даёт `TypeError: 'str' object is not callable` | выбрать другое имя: `message` |
