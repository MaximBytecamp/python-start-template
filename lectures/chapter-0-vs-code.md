# Глава 0. Visual Studio Code: установка и первый проект

Глава справочника: [0 Visual Studio Code: установка и первый проект](https://python-theory-makarov.vercel.app/temy/00-vs-code/index.html)  
Практическая работа: [`practice/00-first-project`](../practice/00-first-project/README.md)

## Что изучили

1. Для работы нужны три программы. Интерпретатор Python читает код и выполняет его. Редактор VS Code нужен, чтобы набирать и сохранять код. Терминал — окно, где команды отдаются компьютеру текстом; из него запускается программа и в нём виден её вывод.
2. Проверка установки: `python --version` на Windows, `python3 --version` на macOS и Linux. На Windows при установке Python отмечается пункт **Add python.exe to PATH**.
3. Проект открывается в VS Code целой папкой: **Файл → Открыть папку…**. Имя папки — латиницей без пробелов (`zayavki`, `python_kurs`). Папку проекта не создают в «Загрузках» и на рабочем столе: там файлы теряются среди скачанного и удаляются при очистке. В облачных папках вроде OneDrive синхронизация иногда блокирует файл в момент записи.
4. Первый файл — `main.py` с одной строкой `print("Hello, world!")`. Расширение `.py` обязательно: по нему редактор включает подсветку и кнопку запуска ▷.
5. Из расширений ставится одно — **Python** от Microsoft. Версия интерпретатора выбирается в строке состояния внизу окна: нужна 3.12 или новее.
6. Запуск из терминала: `python main.py` (macOS — `python3 main.py`). Файл ищется в текущей папке терминала, поэтому команда `cd` переводит терминал в папку проекта.
7. Сообщение об ошибке читается снизу вверх: в последней строке вид ошибки, выше — файл и номер строки.

## Термины

| Термин | Значение |
|---|---|
| интерпретатор | программа, которая читает код на Python и выполняет его |
| редактор кода | программа для набора и сохранения текста программы; выполняет код интерпретатор |
| терминал | окно для текстовых команд; в нём запускается программа и печатается её вывод |
| папка проекта | папка, в которой лежат все файлы курса; в VS Code открывается целиком |
| расширение | дополнение к VS Code; для курса нужно одно — Python от Microsoft |

## Две первые программы главы

```python
# main.py
print("Hello, world!")

# zayavka.py
name = input("Ваше имя: ")
age = int(input("Ваш возраст: "))
print(f"{name}, через год вам будет {age + 1}")
```

## Частые ошибки

| Что написано | Что произойдёт | Как правильно |
|---|---|---|
| при установке на Windows не отмечен Add python.exe to PATH | `python не является внутренней или внешней командой` | запустить установщик заново, выбрать Modify и добавить в PATH |
| в VS Code открыт отдельный файл | терминал открывается не в той папке | Файл → Открыть папку… |
| файл сохранён как `main.py.txt` | нет подсветки и кнопки ▷ | имя заканчивается на `.py` |
| файл не сохранён перед запуском | выполняется прошлая версия кода | Ctrl + S; точка на вкладке означает несохранённые изменения |
| файл назван `print.py` или `random.py` | имя файла перекрывает встроенный модуль | не занимать имена встроенных модулей и функций |
