# Домашние задания

Одно домашнее задание — одна папка `dz-NN-<тема>`. Номер ДЗ пишется двумя цифрами.

| Папка | Что внутри |
|---|---|
| [`dz-00-obrazec`](dz-00-obrazec/README.md) | образец оформления: так выглядит папка сданного ДЗ |

## Что лежит в папке ДЗ

| Файл | Что в нём |
|---|---|
| `README.md` | что задано, список файлов, примеры запуска |
| `zadacha_1.py`, `zadacha_2.py`, … | по одному файлу на задачу |

Если ДЗ — задачи из задачника, решения кладутся в папку [`zadachnik`](../zadachnik/README.md),
а в `README.md` папки ДЗ пишется, какие задачи заданы и где лежат решения.

## Как сдать

1. Создайте папку, например `dz-01-peremennye`, скопировав `dz-00-obrazec`.
2. Замените задание и файлы на свои.
3. Загрузите папку в репозиторий (порядок описан в [`README.md`](../README.md#как-загружать-работы) репозитория).
