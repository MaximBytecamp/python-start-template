# Практическая работа 0. Первый проект в VS Code

Глава справочника: [0 Visual Studio Code: установка и первый проект](https://python-theory-makarov.vercel.app/temy/00-vs-code/index.html)
Конспект: [`lectures/chapter-0-vs-code.md`](../../lectures/chapter-0-vs-code.md)

## Что сделано

1. Установлены Python 3.12 и VS Code, в VS Code установлено расширение Python от Microsoft.
2. Папка открыта через **Файл → Открыть папку…**.
3. Создан файл `main.py`, запущен кнопкой ▷ и командой в терминале.
4. Создан файл `zayavka.py` с вводом имени и возраста. Имя файла взято из главы 0.

| Файл | Что делает |
|---|---|
| [`main.py`](main.py) | выводит `Hello, world!` |
| [`zayavka.py`](zayavka.py) | спрашивает имя и возраст, выводит возраст через год |

## Запуск

```bash
python main.py      # Windows
python3 main.py     # macOS
```

## Результат

```
Ваше имя: Анна
Ваш возраст: 17
Анна, через год вам будет 18
```
